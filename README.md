# Sisweb Frontend

Frontend desarrollado con React, Vite, TypeScript y Tailwind CSS para visualizar productos obtenidos desde un backend Express con PostgreSQL.

## Descripción

Este proyecto implementa una interfaz sencilla tipo dashboard para consultar productos desde una API. Incluye navegación básica, una página de inicio, una pantalla de productos con filtros visuales y una tabla conectada al backend.

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Heroicons

## Requisitos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Node.js
- npm
- Backend corriendo en `http://localhost:3000`

## Instalación

```bash
npm install
```
